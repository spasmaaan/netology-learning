# Домашнее задание к занятию 17 «Инцидент-менеджмент»

## Задание

Составьте постмортем на основе реального сбоя системы GitHub в 2018 году.

Информацию о сбое можно изучить по ссылкам ниже:

* [краткое описание на русском языке](https://habr.com/ru/post/427301/);
* [развёрнутое описание на английском языке](https://github.blog/2018-10-30-oct21-post-incident-analysis/).

| **Воздействие** | 24 часа и 11 минут ухудшения обслуживания. Отображение устаревших метаданных и их долгая подгрузка. Невозможность оставлять комментарии. |
| **Обнаружение** | Дежурные инженеры среагировали 21 октября 2018 г. в 22:54 UTC. |

| **Восстановление** | Восстановление данных во всех ЦОДах. Ожидание репликации всех кластеров до актуального состояния. Запуск push-уведомлений и GitHub Pages. Ожидание выполнения всех накопившихся уведомлений и сборок. |
